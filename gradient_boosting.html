MAE

The average absolute difference between actual and predicted yield.

RMSE

Prediction error that gives greater weight to larger errors.

R²

The proportion of variance in crop yield explained by the model.

⚠ Read these scores carefully

  • Production leakage: Yield is Production ÷ Area, so including both as inputs makes the task easier than real forecasting.
  • Check with Production removed (same model, same split): MAE {{ a.metrics_no_prod.mae|num(3) }}, RMSE {{ a.metrics_no_prod.rmse|num(3) }}, R² {{ a.metrics_no_prod.r2|num(4) }}.
  • Outliers dominate R²: a few crops with very large yield values (e.g. coconut) heavily influence MSE/RMSE/R². MAE is the more representative error here.
